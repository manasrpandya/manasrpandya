# Welcome to My Blog

This is a sample blog post to demonstrate how the blog section works. You can write your blog posts in Markdown format, which makes it easy to create well-formatted content.

## How to Write Blog Posts

1. Create a new markdown file in the `blog/` directory
2. Name it following the format: `YYYY-MM-DD-title.md`
3. Add the frontmatter at the top (title, date, description)
4. Write your content in Markdown format

## Features

- Markdown support
- Code highlighting
- Images and links
- Lists and tables
